회원 탈퇴 Saga (Choreography)

  1. user: WITHDRAWAL_PENDING + Outbox → user.withdrawal.requested
  2. match: 소유 매치 삭제 · 참가 해제 · 차단 → match.withdrawal.completed
  3. user: WITHDRAWN 확정 · Redis Refresh Token 삭제
  4. 실패 시 match.withdrawal.failed → user 가 ACTIVE 로 보상 복원, notification 이 메일 발송
